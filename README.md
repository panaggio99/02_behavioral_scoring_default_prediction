# Прогноз дефолта на горизонте 12 месяцев

## Проблема

Рост просроченной задолженности (90+ дней) в розничном кредитном портфеле.
Традиционные модели кредитного скоринга оценивают риск на момент выдачи
и не помогают с уже действующими клиентами. Банку нужен инструмент,
который заблаговременно выявляет ухудшение поведения заёмщиков.

## Решение

Модель поведенческого скоринга, которая ежемесячно оценивает риск дефолта
по транзакционному поведению, кредитному профилю и макроэкономике.
На тестовой выборке (2018 год): ROC-AUC 0.908, Approval Rate 68.9%,
Default Rate 0.30%, Missed Defaults Rate 1.97%.

Экономический эффект: модель позволяет не создавать резервы на ~3.1 млрд руб.
в год на тестовом портфеле (~8900 клиентов) при нетто-эффекте ~2.7 млрд руб.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows
pip install -r requirements.txt
jupyter notebook notebooks/behavioral_scoring_default_prediction.ipynb
```

Данные положить в `data/` (8 CSV-файла). При запуске ноутбука 
путь определяется автоматически: локальная папка `data/`.

## Стек

Python 3.9+, pandas, scikit-learn, optuna, matplotlib, seaborn, joblib

## Ключевые решения

- Целевая переменная: скользящее окно 12 месяцев, исключение уже случившихся
  дефолтов, исключение 2019 года (артефакт обрезки горизонта).
- Анти-leakage: транзакции через `merge_asof(allow_exact_matches=False)`,
  макроданные со сдвигом +1 месяц.
- Временная кросс-валидация: кастомный `GroupTimeSeriesSplit` по уникальным
  датам (expanding window), а не по индексам строк.
- Оптимизация по бизнес-метрике (`missed_defaults_rate`), а не по ROC-AUC.
- Порог классификации подобран под три бизнес-ограничения одновременно.
